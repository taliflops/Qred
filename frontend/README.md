# Frontend service

The React/Vite client renders the responsive Qred dashboard and sends user commands to the backend.

## Features

- Mobile-first layout matching the supplied dashboard reference.
- Responsive desktop layout without changing the information hierarchy.
- Company selector, menu drawer, card activation, and support action states.
- API-backed data loading with a local loading and error state.

Run with `npm run dev` from the repository root or this directory.
